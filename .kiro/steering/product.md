# Product Overview

**Ademy** is an African-focused online learning platform connecting trainers with learners through video-based courses.

## Core Value Proposition
- African trainers create and monetize educational content
- Learners access quality courses with progress tracking
- Multi-language support (French/English)
- XAF currency integration for African markets

## User Roles
- **Admin**: Platform management, user oversight, course moderation
- **Trainer**: Create courses, upload video lessons, manage content
- **Learner**: Browse courses, enroll, watch videos, track progress

## Key Features
- Video-based learning with Bunny.net CDN
- Course enrollment and progress tracking
- Payment integration (PayUnit for mobile)
- Multi-platform: Web admin panel + React Native mobile app
- Internationalization with French as default language
