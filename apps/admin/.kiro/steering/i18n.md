# Internationalization (i18n)

## Overview

The app supports French and English translations with French as the default language.

## Implementation

- **Translation files**: `lib/i18n/translations.ts` contains all translation keys
- **Context**: `lib/i18n/context.tsx` provides the `useTranslation` hook
- **Language switcher**: `components/language-switcher.tsx` allows users to change language
- **Default language**: French (fr)

## Usage in Client Components

```tsx
"use client"

import { useTranslation } from "@/lib/i18n/context"

export function MyComponent() {
  const { t } = useTranslation()

  return <h1>{t("nav.home")}</h1>
}
```

## Adding New Translations

1. Add the key to both `en` and `fr` objects in `lib/i18n/translations.ts`
2. Use the key with the `t()` function in components

## Language Persistence

The selected language is stored in `localStorage` and persists across sessions.

## Language Switcher

Add the language switcher to navigation components:

```tsx
import { LanguageSwitcher } from "@/components/language-switcher"

<LanguageSwitcher />
```
